Features

What you get

  • Deterministic renders

    Every sample is a pure function of the patch and its time, and the band-limiting filter ships as data with a checksum. The same patch renders to the same samples, run after run.

  • Alias-free by construction

    Synthesis runs at 16 times the sample rate. A frozen minimum-phase filter removes everything above half the base rate by at least 110 dB, and nothing rings before the kick.

  • The patch travels with the sound

    Every WAV carries its patch text. ballast extract gives it back byte for byte, comments included.

  • Strict, complete patches

    Every field is required and nothing is clamped. An invalid patch is refused with every problem and its field path.

  • Live audition

    Plays the exact render buffer, renders again on every save, and loops your bass line under the hits in tempo.

  • Sampler-ready files

    The root key sits in the smpl chunk. 16- and 24-bit exports use seeded TPDF dither that never clips.

Design

How a kick is made

A kick has two sources, a tonal body and a short attack. Ballast sums them into one saturator, computes everything at 16 times the sample rate, and band-limits the result once.

Anatomy of a patch

A patch is a complete TOML description of one kick. Three curves shape it: a pitch curve, as a ratio to the tuning, and two amplitude shapes that start and end at zero and peak at exactly one. Levels are separate gains in dB.

  • Body. The body is sin φ + h₂ sin 2φ. With phase_ref = "tail" it meets the free-running sine at tune_hz exactly from the last pitch knot on, whatever the sweep does before it.
  • Attack. A sine at tone_hz and band-limited noise, mixed at constant power. The noise is a seeded continuous-time process: identical at every sample rate, and editing the band reweights the same noise.
  • Drive. drive.db is the small-signal gain of a tanh saturator, normalized so full scale stays at full scale. 0 dB is an exact bypass.
  • Output. A gain or a peak target, then polarity. Nothing is ever clipped: a render over full scale is refused, and the report says by how much to lower it.
  • Strict. Every field is required and the renderer has no defaults, so a future default can never change an old patch.

Spectrum

Band-limiting

One frozen minimum-phase FIR per sample-rate family turns the internal rate into the file's rate. It ships as data with a SHA-256 checksum, so the sound cannot drift with SciPy versions, and its taps sum to exactly one.

Get started

Get started

With uv, from a checkout of this repository. Audition also needs PortAudio.

$ uv sync --extra audition
$ uv run ballast init tight --tune F1 -o kick.toml     # a complete starting patch
$ uv run ballast audition kick.toml --watch --bpm 128 # plays it; renders again on every save
$ uv run ballast render kick.toml -o kick.wav         # mono WAV with root note and patch
$ uv run ballast extract kick.wav                     # the patch text back from the file
